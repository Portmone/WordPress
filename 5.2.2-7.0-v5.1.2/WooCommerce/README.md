# Portmone.com  Payment Gateway для WooCommerce

Creator: Portmone.com   
Tags: Portmone, WordPress, wooCommerce, payment, payment gateway, credit card, debit card    
Requires at least: WordPress  5.2.2, wooCommerce: 4.0.0
License: Payment Card Industry Data Security Standard (PCI DSS) 
License URI: [License](https://www.portmone.com.ua/r3/uk/security/) 

Версія плагіна: 5.1.2

Плагін додає Portmone.com  як спосіб оплати у ваш інтернет-магазин на WordPress. Прийом платежів за картками VISA та MasterCard, оплата частинами, автоматична фіскалізація чеків, преавторизація та розщеплення платежу.

Для роботи плагіна необхідний акаунт мерчанта в Portmone.com : https://business.portmone.com.ua/signup

### Вимоги

- WordPress 5.2.2 або новіше
- PHP 7.4 або новіше
- WooCommerce 4.0.0 або новіше

### Встановлення

1. Автоматично:

   - Перейдіть на сторінку Плагіни: /wp-admin/plugins.php
   - Натисніть Додати новий, далі Завантажити плагін
   - Оберіть архів portmone-pay-for-woocommerce.zip і встановіть

2. Вручну:

   - Розпакуйте архів і помістіть папку portmone-pay-for-woocommerce у директорію /wp-content/plugins/
   - Активуйте плагін на сторінці Плагіни

### Оновлення

Якщо у вас встановлена попередня версія плагіна, після оновлення відкрийте його налаштування і натисніть Зберегти зміни. У версії 5.1.1 додані поля, значення яких зберігаються тільки після збереження налаштувань.

### Швидкий старт

1. Перейдіть у WooCommerce -> Налаштування -> Платежі -> Portmone -> Налаштувати, або скористайтеся пунктом Portmone в меню адмінпанелі.
2. Заповніть обов'язкові поля:
   - Включити прийом оплати через Portmone.com
   - Ідентифікатор магазину в системі Portmone (Payee ID)
   - Логін інтернет-магазину в системі Portmone
   - Пароль інтернет-магазину в системі Portmone
   - Ключ для підпису
3. Натисніть Зберегти зміни.

Payee ID, логін, пароль і ключ для підпису надає менеджер Portmone.com . Решту параметрів заповніть за потреби, їх опис наведено в документації.

### Можливості

- Оплата картками VISA та MasterCard на захищеній сторінці Portmone.com
- Оплата частинами через банки-партнери (розтермінування, потребує окремого погодження)
- Автоматична фіскалізація чеків з передачею позицій замовлення, знижок, штрих-кодів і доставки
- Попередня авторизація коштів з підтвердженням або скасуванням в адмін-панелі магазину
- Повне та часткове повернення коштів
- Розщеплення платежу між декількома компаніями
- Обмеження часу на оплату
- Асинхронні нотифікації про оплату
- Автоматичне зменшення залишків на складі після оплати
- Передача даних покупця (ПІБ, телефон, email) для відображення у квитанції
- Робота з валютою. Portmone.com  приймає платежі виключно в гривні (UAH). Платежі у валютах USD, EUR, GBP, PLN, KZT конвертуються в UAH за курсом НБУ або за власним курсом магазину
- Режим тестування

### Обмеження

- Автофіскалізація доступна тільки для магазинів з валютою UAH
- Скасування або повернення коштів можливе лише у валюті UAH
- Розтермінування не можна оформити в одному платежі з розщепленням
- Заблоковані кошти можна скасувати тільки повністю, часткове повернення недоступне. Підтвердження списання при цьому можливе на суму, меншу за заблоковану
- Часткове повернення недоступне, якщо увімкнена автофіскалізація і до замовлення застосовано купон
